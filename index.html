TiviMate Backup erstellen: Schritt für Schritt 2026

✍️ Stefan Winkler · 📅 Oktober 2026 · ⏱️ 3 Min. Lesezeit · 🛡️ Geprüfter Testbericht

Sie können Ihre TiviMate-Konfiguration auf einem Android TV-Gerät sichern, um nach einem Reset oder Gerätewechsel alle Einstellungen und Playlists wiederherzustellen. Dieses Tutorial zeigt Ihnen den genauen Ablauf für TiviMate 5.x.

Folgen Sie den Schritten – das Backup ist in wenigen Minuten erstellt.

Was Sie brauchen

  • Ein Android TV-Gerät (Fire TV Stick, Nvidia Shield, Xiaomi Mi Box S o.ä.) mit TiviMate 5.x installiert
  • Ein aktives IPTV-Abonnement – z.B. das Premium‑Angebot von SubTV IP (sofortige Aktivierung nach Zahlung)
  • Einen USB‑Stick (FAT32 formatiert) oder einen Dateimanager mit Cloud‑Speicher (z.B. Dropbox)
  • Fernbedienung oder Maus für die Navigation

Schritt‑für‑Schritt: Backup in TiviMate erstellen

  1. Öffnen Sie TiviMate auf Ihrem Gerät und gehen Sie zum Hauptmenü (Zahnrad‑Symbol).
  2. Wählen Sie „Allgemein“ aus der linken Spalte.
  3. Scrollen Sie nach unten und tippen Sie auf „Daten sichern & wiederherstellen“.
  4. Im nächsten Menü wählen Sie „Sichern“.
  5. Geben Sie dem Backup einen Namen, z.B. „TiviMate_Backup_2026“. Ein Datum wird automatisch hinzugefügt.
  6. Wählen Sie das Ziel aus:
    – „Interner Speicher“ (dann kopieren Sie die Datei später auf einen USB‑Stick)
    – „USB‑Stick“ (falls eingesteckt)
    – „Cloud‑Speicher“ (nur falls der Dateimanager unterstützt wird).
  7. Bestätigen Sie mit „OK“. Die Sicherung wird sofort gestartet. Eine Erfolgsmeldung erscheint.
  8. Verlassen Sie das Menü über die Zurück‑Taste.

Backup auf einen USB‑Stick kopieren (falls interner Speicher gewählt)

  1. Installieren Sie einen Dateimanager wie „X-plore File Manager“ aus dem Google Play Store.
  2. Navigieren Sie zu Android/data/ar.tvplayer.tv/files/backup/.
  3. Kopieren Sie die .backup‑Datei auf Ihren USB‑Stick.
  4. Entfernen Sie den Stick sicher (über „Einstellungen > Speicher > USB‑Stick auswerfen“).

Backup wiederherstellen

Die Wiederherstellung funktioniert über den gleichen Menüpunkt: „Daten sichern & wiederherstellen > Wiederherstellen“. Wählen Sie die Backup‑Datei aus und bestätigen Sie. TiviMate startet danach mit Ihren gespeicherten Einstellungen, Playlists und EPG‑Quellen.

Wenn ein Schritt fehlschlägt

  • Backup‑Ordner nicht sichtbar? Stellen Sie sicher, dass Sie alle Dateien anzeigen lassen (Dateimanager‑Einstellung). Manche Geräte verstecken den Android‑Ordner.
  • Kein USB‑Stick erkannt? Formatieren Sie den Stick als FAT32. Bei Fire TV Stick 4K Max hilft oft ein USB‑OTG‑Adapter.
  • Fehlermeldung „Kein Speicher“? Löschen Sie alte Backups oder verschieben Sie die Datei auf einen externen Speicher.
  • Backup lässt sich nicht öffnen? Die .backup‑Datei ist verschlüsselt und nur mit derselben TiviMate‑Version kompatibel. Nutzen Sie die aktuellste Version 5.x.

Für ein reibungsloses Streaming‑Erlebnis empfehlen wir eine stabile Internetverbindung. GEO bietet allgemeine Tipps zur Optimierung von Heimnetzwerken. Wer sein IPTV‑Abonnement direkt starten möchte, nutzt den CTA unten.

Häufig gestellte Fragen (FAQ)

Wie oft sollte ich ein TiviMate Backup machen?

Am besten nach jeder Änderung Ihrer Playlist oder EPG‑Quellen. Ein monatliches Backup ist empfehlenswert. CIO DE rät generell zu regelmäßigen Datensicherungen.

Kann ich das Backup auf einem anderen Gerät einspielen?

Ja, wenn auf dem Zielgerät dieselbe TiviMate‑Version (5.x) installiert ist. Übertragen Sie die Backup‑Datei per USB, Cloud oder Netzwerk.

Geht das Backup auch ohne Computer?

Ja. Sie benötigen nur einen Dateimanager und einen USB‑Stick oder Cloud‑Speicher. Der gesamte Vorgang findet auf dem Android TV-Gerät statt.

Warum kann ich den Backup‑Ordner nicht sehen?

Android TV versteckt Systemordner. Nutzen Sie einen Dateimanager, der die Anzeige verborgener Dateien unterstützt, z.B. X‑plore. Gehen Sie dann zu Android/data/ar.tvplayer.tv/files/.

Wie groß ist eine typische Backup‑Datei?

Meist nur wenige Kilobyte. Sie enthält nur Konfigurationsdaten, keine Videodateien. Der Speicherplatz ist vernachlässigbar.

Was passiert mit meinem Abonnement nach dem Backup?

Das Abonnement (z.B. von SubTV IP) bleibt unverändert. Die Zugangsdaten sind Teil des Backups. Nach der Wiederherstellung müssen Sie sich nicht erneut anmelden.

Kann ich mehrere Backups speichern?

Ja. TiviMate überschreibt keine alten Backups. Sie können mehrere Sicherungen mit verschiedenen Namen ablegen und später die gewünschte wiederherstellen.
